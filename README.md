# filimonov_cartrading

Статический одностраничный сайт: продажа автомобилей, услуги, контакты и юридические модальные окна.

## Содержимое

- `index.html` — вся страница, стили и JavaScript.
- `assets/` — изображения, логотип SVG и иконка сайта.
- `.gitlab-ci.yml` — публикация в GitLab Pages из основной ветки (современный GitLab, 17.10+).

Сборка и установка зависимостей не нужны. Можно открыть `index.html` в браузере. Шрифты Google Fonts требуют подключения к интернету.

## GitLab

1. Распакуйте ZIP.
2. Создайте пустой проект GitLab.
3. Загрузите распакованные файлы в корень репозитория, включая `.gitlab-ci.yml` и всю папку `assets` (не сам ZIP).
4. Сделайте commit в основную ветку. При включённых GitLab Pages и доступном CI Runner запустится публикация.
5. После успешного pipeline адрес будет доступен в Deploy → Pages.

Документация: https://docs.gitlab.com/user/project/pages/getting_started/pages_from_scratch/

## Редактирование

Все тексты и настройки находятся в `index.html`. Тексты Impressum и Datenschutz — в шаблонах `legal-impressum` и `legal-datenschutz`. Данные карточек автомобилей — в секции `fahrzeuge`.

## Что осталось заполнить

- Полный адрес и рабочий e-mail Вадима.
- Реальные автомобили: фотографии, модель, характеристики, цена и наличие.
- Подтверждённый список услуг.
- Сведения о хостинге в Datenschutz: архив содержит текст для текущей закрытой версии ChatGPT Sites. При переносе в GitLab замените этот раздел на фактические сведения о GitLab/вашем хостинге, обработчиках, странах, защите данных и сроках хранения.

Юридические тексты остаются черновыми. Изображения автомобилей и мастерской иллюстративные. Форма готовит текст для копирования и не отправляет сообщения.

Это самостоятельный экспорт текущей версии. Изменения в GitLab не синхронизируются автоматически с опубликованной версией ChatGPT Sites.
